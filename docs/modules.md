# Modules

Generated by `scripts/update-docs.py` from the module docstrings. The modules form two libraries: the main library `CCDN` (below `CCDN/`), which the main results, `Solution.lean` and the comparator use, and the paper library `CCDNPaper` (below `CCDNPaper/`), which imports `CCDN` and holds the parts of the paper that the main results do not use. `CCDN` never imports `CCDNPaper`. Within them the directories form tiers, which `scripts/check-layers.py` enforces:

* `CCDN/`: `Statements.lean` states the main results and imports only the foundation; each other module is the endpoint of one result and is imported by no library module.
* Foundation (`ForMathlib/`, `Algebra/`, `Analysis/`, `Height/`, `Hilbert/`): general results, which import only Mathlib, the vendored libraries and each other.
* Topics (the other directories of `CCDN/`): the proof routes, each in the directory of its topic.
* `CCDNPaper/Center/`: Section 5 of the paper, formalised as printed (with the corrections of the discrepancy table) but used by no main result.
* Side results (`CCDNPaper/Counterexample/`, `CCDNPaper/Statements/`): counterexamples, and the paper's intermediate statements as stated there; imported by no other directory.

record, not maintained: module paths, declaration names and some statements have changed
since. Before the library was reorganised into directories, all modules lived in `CCDN/`, and
before that in `AffineCurveCounting/`.

For the current state, see the README, [`../overview.md`](../overview.md),
[`../statements.md`](../statements.md) and [`../completion-audit.json`](../completion-audit.json).
